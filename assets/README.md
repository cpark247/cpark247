# Images for the profile README

The profile page expects four images here. Until they exist the cards show broken images, so add them before making the repository public.

| File | Card | Suggested content |
|---|---|---|
| `paper.png` | diffuser-gas-accumulation | Gas accumulation in the diverging channel (void-fraction iso-surface or time-averaged slice), baseline vs. surface structures |
| `virtual-hole.png` | virtual-hole-method | Sketch: blade with meshed holes vs. the same blade with cyclicACMI patch pairs and a pressure jump. Generic drawing only, no partner geometry |
| `validation.png` | turbulence-validation-OF9 | One clean comparison plot, e.g. channel-flow U⁺ vs y⁺ for RANS / SAS / LES against DNS (`turbulence-validation-OF9/scripts/plot_profiles.py`) |
| `library.png` | openfoam9-multiphase-les-extensions | Code-to-physics diagram of the solver family, or a snapshot of resolved turbulence from an LES run |

Use the same size for all four (about 800 × 500 px) so the cards line up. Keep each file under ~500 kB.
